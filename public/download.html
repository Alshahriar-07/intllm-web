Download INTLLM

Official release artifacts are published on GitHub Releases with a SHA256.txt manifest — the installers below verify checksums automatically before use.

Windows

Available

Windows 10/11 x64. Per-user install under %LOCALAPPDATA%\Programs\INTLLM; runtime data is kept separately in %LOCALAPPDATA%\INTLLM.

Download for Windows INTLLM-windows-x64.exe · Windows x64 · INTLLM-Setup.exe (v1.0.1) also available
PowerShell 
irm https://intllm.vercel.app/install.ps1 | iex

macOS

Requires Python 3.11+

Installs the universal Python wheel into an isolated venv at ~/.intllm and exposes an intllm command. Apple Silicon and Intel supported.

Download for macOS intllm-0.4.2-py3-none-any.whl · macOS
Shell 
curl -fsSL https://intllm.vercel.app/install.sh | bash

Linux

Requires Python 3.11+

Same universal wheel: installs into ~/.intllm, adds ~/.local/bin to your PATH, and verifies the SHA256 checksum before installing.

Download for Linux intllm-0.4.2-py3-none-any.whl · Linux
Shell 
curl -fsSL https://intllm.vercel.app/install.sh | bash
01

Verify checksums

Every release ships a SHA256.txt manifest. The one-line installers verify it automatically; to verify manually:

bash 
sha256sum -c SHA256.txt
PowerShell 
Get-FileHash .\INTLLM-windows-x64.exe -Algorithm SHA256
02

External dependencies

INTLLM does not bundle or silently install its external local dependencies — it detects and reports them at startup:

  • Ollama, running with at least one model pulled
  • PostgreSQL 14+ with the pgvector extension
  • Python 3.11+ (only for the Linux/macOS wheel path)

After installing, follow the install guide for first-run steps.
