Quickstart

Install INTLLM

Official release installers download, verify checksums via SHA256.txt, and register the intllm CLI in your environment.

Terminal
> irm https://intllm.vercel.app/install.ps1 | iex
Windows 10/11 x64 · Download SHA256 verified

Manual / pip installation

For developers running within customized Python virtual environments (Python 3.11+): 

pip install intllm
intllm doctor

Verifying Readiness

After installation, run intllm doctor in your shell. It checks connection to your local Ollama daemon and local PostgreSQL database with pgvector, reporting any misconfigurations transparently.
