Install INTLLM

The installers download the correct release artifact from GitHub Releases, verify its SHA256 checksum against the published SHA256.txt, and install INTLLM for the current user.

1 — Run the one-line installer (PowerShell)

PowerShell 
irm https://intllm.vercel.app/install.ps1 | iex

Downloads INTLLM-windows-x64.exe, verifies its SHA256, installs under %LOCALAPPDATA%\Programs\INTLLM, adds it to your user PATH and creates a Start Menu shortcut. Runtime data lives separately in %LOCALAPPDATA%\INTLLM and survives upgrades and uninstall.

2 — Verify and start

PowerShell 
INTLLM --version
INTLLM doctor
INTLLM

Open a new terminal so the updated PATH is picked up. INTLLM doctor checks PostgreSQL, pgvector and Ollama readiness.

1 — Run the installer (requires Python 3.11+)

Shell 
curl -fsSL https://intllm.vercel.app/install.sh | bash

Downloads the universal wheel intllm-0.4.2-py3-none-any.whl, verifies its SHA256, installs it into an isolated virtual environment at ~/.intllm and exposes an intllm command in ~/.local/bin.

2 — Verify and start

Shell 
intllm --version
intllm doctor
intllm

If intllm is not found, open a new shell so the PATH edit applies.

1 — Run the installer (requires Python 3.11+)

Shell 
curl -fsSL https://intllm.vercel.app/install.sh | bash

Same flow as macOS: checksum-verified wheel, isolated venv at ~/.intllm, wrapper script in ~/.local/bin. Set INTLLM_NO_PATH_EDIT=1 to skip shell rc edits.

2 — Verify and start

Shell 
intllm --version
intllm doctor
intllm

Install with pip (from a release wheel / PyPI when published)

Shell 
python -m pip install intllm

Console scripts: intllm (CLI) and intllm-api (API server). Requires Python 3.11+.

From source (development)

Shell 
git clone https://github.com/Alshahriar-07/INTLLM.git
cd INTLLM
npm install && npm run build
python -m pip install -e "./backend[dev]"
01

After installing

  1. Install Ollama and pull at least one model — INTLLM detects the daemon automatically.
  2. Install PostgreSQL 14+ with the pgvector extension — INTLLM verifies reachability and schema on startup.
  3. Run intllm doctor to check readiness, then intllm to start the runtime; the web UI opens in your browser.
  4. Pull or select a model in Models, create an API key in Settings → API, and start chatting.

INTLLM does not bundle or silently install Ollama or PostgreSQL — it detects and reports their state honestly at startup.
