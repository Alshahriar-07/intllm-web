About

I build INTLLM — a local-first AI runtime that keeps models, memory, tools and data on your own machine. INTLLM started from a simple observation: local models are good reasoning engines, but they have no memory of your context and no access to current information. So INTLLM supplies the surrounding runtime — layered memory, optional live retrieval, a permission-gated tool gateway and an OpenAI-compatible local API — without sending anything to the cloud.

The project is open source under the MIT License and lives on GitHub. Development, releases and issues all happen in public.
