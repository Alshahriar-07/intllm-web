01

What is INTLLM?

INTLLM is a local-first AI runtime built around local models served by Ollama. It is the orchestration layer around the model — not the model itself: layered memory, optional live web retrieval, a permission-gated tool gateway and an OpenAI-compatible local API, with conversations and data staying local by default.

02

What it does

chat

Local chat with streaming

Talk to any model in your Ollama inventory, with token streaming and activity labels.

/v1

OpenAI-compatible local API

/v1/models and /v1/chat/completions (streaming SSE), routed through the same runtime as the UI.

L0 / L1 / L2

Layered memory

Flash Brain, Hot Cache and Secondary Brain in local PostgreSQL + pgvector, with confidence and freshness scoring.

web

Live information retrieval

Optional per-request web search with source attribution, trust scores and SSRF protection.

tools

Controlled tools

A permission-gated tool gateway for browser automation and workspace-scoped filesystem access.

status

Honest status reporting

PostgreSQL, pgvector and Ollama states are detected and reported — nothing is fabricated.
